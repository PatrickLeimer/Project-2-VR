Ensure to downlaod these assets to your local machine to ensure the project works properly

Also, make sure to crreate a folder within the "Assets" folder named "AssetLibraries" this is where you can store asset libraries downloaded to your machine and they will be ignored by the project

Japanese Garden: https://assetstore.unity.com/packages/3d/vegetation/trees/japanese-garden-pack-179492

Japanese Garden 2: https://assetstore.unity.com/packages/3d/vegetation/japanese-garden-2-free-327670

Robot Kyle: https://assetstore.unity.com/packages/3d/characters/robots/robot-kyle-urp-4696

Zen Garden Area: https://assetstore.unity.com/packages/3d/props/khs-donggung-304769

To ensure pond work's properly follow Isa's instructions here: https://github.com/PatrickLeimer/Project-2-VR/pull/5

To make gazebo, and sushi, tea cup set, and bench to work download the zip file and download the remaining assets via the links in the Unity Asset Store:
https://github.com/PatrickLeimer/Project-2-VR/pull/12

After downloading the zip file from the PR and extracting it, place it in the AssetLibraries folder to avoid it being tracked.
